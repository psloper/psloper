Controls

Gamepad / Transmitter

  • Left stick — Throttle (Y) / Yaw (X)
  • Right stick — Pitch (Y) / Roll (X)
  • Start / Options — Arm / Disarm
  • Select / Back — Respawn

Keyboard

  • W / S — Throttle up / down
  • A / D — Yaw left / right
  • ↑ / ↓ — Pitch forward / back
  • ← / → — Roll left / right
  • Enter — Arm / Disarm
  • Backspace — Respawn
  • C — Toggle FPV / Chase camera
  • Esc / P — Pause
  • H — Toggle this help

Tip: real FCs refuse to arm with the throttle raised — keep it at zero before arming here too.
